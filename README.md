# Commander Life

Commander life and commander-damage counter for 1–4 players, shared live across every phone that opens the page.

Play at https://biglob.github.io/commander-life/

Archenemy (one archenemy against three heroes): https://biglob.github.io/commander-life/archenemy.html

Source and history: BigLob/Mtg. Live sync runs through a Firebase Realtime Database.
